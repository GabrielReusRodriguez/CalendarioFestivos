# Calculadora de Festivos

 Se ha de crear una aplicacion que calcule los festivos en España ( nacionales, autonómicos y locales) pasándole el año de consulta y la ciudad de consulta. También existirá la opcion de exportarlos a los calenarios online.

# Objetivos 

 Los entregable serán una aplicación web. 
 Ha de ser una aplicacion multi-idioma soportando ( las lenguas oficiales de España ) y entender los nombres de los municipios en esos idiomas.

# Arquitectura

 La aplicacion se hará con los siguientes componentes:
    - Flutter
    - Lenguaje de programacion Dart
    - devcontainer para hacer la instalacion de los componentes

# Estructura de carpetas
 Las carpetas serán las siguientes:
    - .devcontainer con los ficheros necesarios para montar el devcontainer
    - src con el codigo fuente
    - scripts con los scripts auxiliares
    - tests con los tests generados
    - deploy con lo entregables

# Restricciones

 NO se instalará nada fuera de los devcontainers.
